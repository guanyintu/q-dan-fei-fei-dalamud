## 实机排障与待验证项

初次交付时没有运行中的客户端；排障时已发现用户运行的客户端。其卫月日志明确记录：`Unable to load QBounce, game is newer than applicable version 2026.10.06.0000.0000`。游戏实际版本为 2026.11.03，运行时为 15.0.4.0；0.1.0 的固定旧版本上限是本次启用失败的直接原因。

回归命令：`./scripts/Test-PluginCompatibility.ps1 -ManifestPath dist/q弹狒狒-卫月版/q弹狒狒.json -DalamudPath <实际卫月目录> -GameVersionFile <游戏目录/ffxivgame.ver>`。已对旧清单运行并得到失败，重建后的 0.1.1 清单检查通过。构建现在自动选择已安装最新 API 15 运行时，从该运行时生成版本清单；打包前再校验，避免再次交付不匹配的旧版本上限。

该加载预检通过不等于游戏内加载或模型效果通过。“真实模型三轴缩放生效”和“游戏稳定性”仍标为**未验证**。

## 恢复与风险

关闭时只恢复仍与对象身份匹配且未被外部替换的缩放分量。失效、重绘或同地址其他身份的旧状态直接丢弃。没有可用的原生对象世代计数器；两帧之间完全相同身份、地址、虚表与骨架的销毁重建不可完全识别。其他插件基于 QBounce 写入值再加工也无法完全隔离。

无法保证原生异常后恢复；实际出现残留变形时按顺序执行 `/qbounce off`、停用插件、切图／重新登录，必要时停用后重启游戏。特殊模型、骑乘、VFX、GPose 以及原生动画覆盖均不声称已验证支持。没有修改游戏文件或服务器状态，不需要修复文件。
