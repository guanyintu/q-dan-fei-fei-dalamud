# q弹狒狒

[简体中文](README.md) · [繁體中文](README.zh-TW.md) · [English](README.en.md)

Makes everyone bouncy. Author: **someboy**. **Primarily generated by Codex.**

[Download the Dalamud version](https://github.com/guanyintu/q-dan-fei-fei-dalamud/releases/latest) · [Standalone EXE](https://github.com/guanyintu/q-dan-fei-fei-standalone)

The Dalamud version is generally smoother; prefer it if you already use Dalamud. The standalone version works without Dalamud. Enable only one version at a time.

## Install

Add this custom repository in Dalamud settings, then search for `q弹狒狒`:

```text
https://raw.githubusercontent.com/guanyintu/q-dan-fei-fei-dalamud/main/repo.json
```

For manual development loading, extract `latest.zip` and add the full path to `q弹狒狒.dll` under Dev Plugin Locations. Keep its dependencies and `Assets` folder together. Run `/qbounce` and enable the effect; it starts disabled.

Version **0.1.7** targets Dalamud API 15 / .NET 10, validated against CN Dalamud 15.0.4.0 and game 2026.11.03.0000.0000. Release files are the official DalamudPackager output: `latest.zip` and the plugin manifest (GitHub download name `manifest.json`).

## Language and controls

The UI supports Simplified Chinese, Traditional Chinese and English. It follows the Dalamud UI language by default and falls back to English for other languages. A manual choice at the top of the window is saved. Changing language does not restart the effect or music. System/native exception details retain their original text.

Default strength: 0.4; period: 0.45 seconds. Loaded players, NPCs and monsters bounce in sync, with optional random phases. F6 toggles, F7 cycles strength and F8 restarts the rhythm; hotkeys are disabled by default and do not consume game bindings.

## Music

[Music source: Bilibili BV1VGYR6bECg](https://www.bilibili.com/video/BV1VGYR6bECg/). The bundled MP3 is about 3 minutes 7 seconds / 4.50 MB. You may choose another local MP3 or WAV. An explicit selection or configuration-folder `bgm.mp3` takes priority over the bundle. Missing music does not stop the visual effect.

## Build and limits

Install .NET 10 SDK and matching API 15 Dalamud, then run `./build.ps1 -DalamudPath <Dalamud directory>`. The script builds, tests, validates and copies the SDK's original `latest.zip` and manifest without rebuilding the archive. See [validation](docs/VALIDATION.md) and [technical notes](docs/TECHNICAL-NOTES.md).

The effect changes render scale only. Cutscenes, loading and GPose pause it. If a model remains distorted, disable the effect, then change zones or log in again. Compilation, package checks and automated tests do not replace in-game validation of all models, attachments or long sessions.
